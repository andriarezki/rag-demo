# Keamanan Data

## Klasifikasi data

Data dibagi tiga tingkat: Publik, Internal, dan Rahasia. Data pelanggan, gaji, dan kontrak termasuk Rahasia. Data Rahasia hanya boleh disimpan di server file perusahaan dan tidak boleh dikirim ke email pribadi, aplikasi chat pribadi, atau flashdisk.

## Email mencurigakan

Jangan klik tautan atau membuka lampiran dari email yang tidak dikenal, terutama yang meminta Anda segera mengisi password atau mentransfer uang. Laporkan email mencurigakan dengan tombol "Laporkan phishing" di email atau teruskan ke phishing@contoh.id. Jika sudah terlanjur mengklik, segera ganti password dan hubungi tim IT.

## Backup

Server file dicadangkan otomatis setiap malam pukul 01.00 dan cadangan disimpan 30 hari. File di laptop atau desktop tidak ikut dicadangkan, jadi simpan pekerjaan penting di server file atau penyimpanan cloud perusahaan. Permintaan mengembalikan file yang terhapus diajukan ke tim IT, dan file bisa dipulihkan paling lama 30 hari ke belakang.

## Insiden keamanan

Jika Anda menduga ada kebocoran data atau akun diretas, segera hubungi tim IT dan jangan menghapus apa pun. Tim IT akan memulai penyelidikan dan memberi tahu pihak yang terdampak sesuai kebutuhan.
