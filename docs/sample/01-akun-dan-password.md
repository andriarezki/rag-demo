# Akun dan Password

Dokumen ini berlaku untuk semua karyawan PT Contoh Digital. Perusahaan ini fiktif dan dipakai hanya sebagai contoh data.

## Membuat dan mengganti password

Password minimal 12 karakter dan harus berisi huruf besar, huruf kecil, angka, dan satu simbol. Password wajib diganti setiap 90 hari. Sistem mengirim pengingat 7 hari sebelum password kedaluwarsa. Password lama tidak boleh dipakai lagi untuk 5 penggantian berikutnya.

## Lupa password

Jika lupa password, buka halaman akun.contoh.id lalu pilih "Lupa password". Tautan reset dikirim ke email kantor dan berlaku selama 30 menit. Jika email kantor juga tidak bisa dibuka, hubungi tim IT lewat kanal Slack #bantuan-it. Tim IT tidak pernah meminta password lewat chat atau telepon.

## Verifikasi dua langkah

Verifikasi dua langkah (2FA) wajib untuk email, VPN, dan aplikasi keuangan. Gunakan aplikasi autentikator di ponsel. Simpan kode cadangan di tempat aman, bukan di laptop kantor. Jika ponsel hilang, segera lapor ke tim IT agar 2FA lama dicabut.

## Akun yang terkunci

Akun terkunci otomatis setelah 5 kali salah memasukkan password. Akun terbuka lagi sendiri setelah 15 menit, atau bisa dibuka lebih cepat oleh tim IT setelah identitas Anda diverifikasi.
