# VPN dan WiFi

## WiFi perusahaan

Ada dua jaringan WiFi. Jaringan "Contoh-Staf" untuk karyawan dan perangkat perusahaan, memakai login akun perusahaan. Jaringan "Contoh-Tamu" untuk tamu, password berubah setiap hari Senin dan diberikan oleh resepsionis. Perangkat pribadi tidak boleh tersambung ke Contoh-Staf.

## Memakai VPN dari luar lokasi perusahaan

VPN wajib dipakai saat bekerja dari rumah, kafe, atau bandara untuk mengakses sistem internal seperti server file dan aplikasi HR. Pasang aplikasi VPN dari portal perusahaan, login dengan akun perusahaan, lalu masukkan kode 2FA. Sambungan VPN terputus otomatis setelah 8 jam tanpa aktivitas.

## VPN tidak bisa tersambung

Periksa dulu koneksi internet Anda. Lalu pastikan jam di laptop sudah benar, karena jam yang meleset membuat kode 2FA ditolak. Jika masih gagal, tutup aplikasi VPN, buka lagi, dan coba server cadangan di menu pengaturan. Jika tetap gagal, kirim tangkapan layar pesan error ke #bantuan-it.

## Jaringan publik

Jangan membuka data rahasia di WiFi publik tanpa VPN. Jangan memakai fitur berbagi file di jaringan publik.
